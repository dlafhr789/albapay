# 알바페이

근무를 기록하면 급여를 계산하고, 근무 일정을 애플 캘린더에 자동으로 띄워 주는 1인용 웹앱이다.

> 개발 중이다. 진행 상황은 [CHANGELOG.md](CHANGELOG.md)에 있다.

## 만든 이유

쓰던 알바 급여 앱에 두 가지가 없었다.

- 기본 캘린더 연동: 근무 일정을 다른 일정과 한 캘린더에서 보고 싶었다.
- 반복 근무 등록: 매주 같은 근무를 하루씩 따로 입력해야 했다.

## 구성

- 프론트엔드: React + TypeScript PWA. 아이폰 홈 화면에 추가해서 앱처럼 쓴다. 네이티브 앱은 무료 서명이 7일마다 만료돼서 쓰지 않았다.
- 캘린더: 근무 일정을 iCalendar(.ics) 구독 URL로 내보내고, 애플 캘린더가 이 URL을 주기적으로 다시 받아온다. 그래서 캘린더 쪽은 읽기 전용이다.
- 백엔드: AWS Lambda와 DynamoDB. CloudFront 뒤에서만 호출된다.
- 인프라: Terraform으로 관리한다.

## 계산 범위

- 기본급, 주휴수당, 공제(3.3% 또는 4대보험 항목별 선택)를 계산한다.
- 상시 5인 미만 사업장을 전제로 해서 야간·연장·휴일 가산수당은 계산하지 않는다.
